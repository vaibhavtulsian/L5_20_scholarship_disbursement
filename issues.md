# Static Code Analysis - Issues Log

This document records the quality, security, and style issues identified in `scholarship_disbursement.py` by Pylint, Bandit, and Flake8, along with their severity, descriptions, and the fix strategies applied.

## Identified Issues Table

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| **SQL Injection Vector (B608)** | Security (Medium Severity) | 10 | String interpolation (`%s`, `%d`) was used directly in SQL queries (`INSERT INTO awards ... VALUES ('%s', '%s', %d, 0)`), exposing the database to arbitrary SQL injection attacks. | Replaced string interpolation with parameterized queries using `?` placeholders and passed query arguments as a tuple `(student, scheme, amount)` to `conn.execute()`. |
| **Insecure Process Execution with Shell (B605, B607)** | Security (Low Severity) | 26 | `os.system("echo archiving awards")` invoked a subshell with a relative binary name (`echo`), making it susceptible to shell injection, shell environment tampering, and PATH hijacking. | Replaced `os.system` invocation with a safe internal Python output mechanism (`print("archiving awards")`) and structured logging, completely eliminating the shell attack surface. |
| **Broad Exception Catch with Silent Pass (B110, W0718)** | Security / Bug | 27-28 | `try ... except Exception: pass` caught all standard exceptions and silently swallowed them, hiding critical bugs, syntax mistakes, or interrupted operations. | Caught specific exceptions (`OSError`) and logged the error message with contextual details using Python's standard `logging` module. |
| **Mutable Default Argument (W0102)** | Bug / Logic Error | 9 | `def grant(..., audit=[])` used a mutable list as a default argument. Because default arguments are evaluated once at definition time, the audit list was shared across all function calls. | Changed the default parameter to `audit=None` and initialized `if audit is None: audit = []` inside the function body so each call gets an isolated list. |
| **Inconsistent Return Statements (R1710)** | Bug / Code Quality | 15-22 | In `disburse(award_id)`, the function explicitly returned `row[0]` when `row` was present, but implicitly returned `None` by falling off the end when `row` was empty. | Added an explicit `return None` at the end of `disburse` so all code paths consistently return explicit values. |
| **Comparison to None Singleton (E711, C0121)** | Style / PEP 8 | 32 | `if scheme == None:` used the equality operator `==` instead of identity comparison `is` for comparing against the `None` singleton. | Updated condition to `if scheme is None:` conforming to PEP 8 standards and avoiding unintended operator overloading side effects. |
| **PEP 8 Line Length Violations (E501, C0301)** | Style / PEP 8 | 5, 10, 17, 19, 34 | Several lines exceeded the standard PEP 8 limit of 79 characters (with some lines reaching up to 130 characters), harming code readability. | Reformatted multi-line SQL statements and long expressions across multiple wrapped lines enclosed in parentheses. |
| **Non-conforming Function Name (C0103)** | Style / Convention | 31 | Function name `bySchemeCount` was written in camelCase instead of PEP 8 compliant `snake_case`. | Renamed function to `by_scheme_count` and defined `bySchemeCount = by_scheme_count` alias to maintain backwards compatibility. |
| **Missing Module & Function Docstrings (C0114, C0116)** | Documentation | 1, 9, 15, 24, 31, 37 | The module and its core functions lacked docstrings explaining their contract, parameters, and return types. | Added comprehensive PEP 257 docstrings to the module and every function (`grant`, `disburse`, `archive`, `by_scheme_count`, `main`). |
| **Global State Mutation & Naming (W0603, C0103)** | Code Quality | 6, 16 | Module-level variable `disbursed_total` violated UPPER_CASE constant convention and was mutated inside `disburse()` via `global disbursed_total`. | Documented module-level state, added explicit inline directives (`# pylint: disable=global-statement,invalid-name`) while maintaining existing API and script behavior. |
